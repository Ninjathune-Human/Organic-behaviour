# Laboratoire de fusion

Cellules vivantes reliées par des liens routés en orthogonal. Page autonome, sans installation : ouvrir `index.html`, ou la version en ligne sur GitHub Pages.

Sur iPhone et iPad : ouvrir l'adresse dans Safari, puis Partager › Sur l'écran d'accueil pour l'utiliser en plein écran.
